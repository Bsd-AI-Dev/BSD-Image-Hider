You typeIt covers

contoso.com/Only the site’s front page
contoso.com/blog/*Every page whose address starts with contoso.com/blog/
recipesAny address containing the word “recipes”

You can paste full addresses like https://www.contoso.com/home.html; they’re tidied up automatically.

Which rule wins?

The most specific one: page → section (/blog/*) → site → word → default. For example, with contoso.com set to Hide everything and contoso.com/weather/* set to Show images, images are shown on contoso.com/weather/today and hidden everywhere else on contoso.com.

Privacy

This extension has no network access, no analytics and no remote code. Settings are stored only in this browser.
