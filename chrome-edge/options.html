Private Image Hider – Settings

New here? Read how to use the extension.

Show images on…

Sites or pages where images are shown. Everywhere else they are hidden. One entry per line.

Always hide images on…

Pages where images stay hidden even if the site is in the list above. This list always wins.

You typeIt covers
contoso.comThe whole site, including subdomains like shop.contoso.com
contoso.com/home.htmlExactly that one page (anything after ? or # is ignored)
contoso.com/Only the site’s front page
contoso.com/blog/*Every page whose address starts with contoso.com/blog/
recipesAny address containing the word “recipes”

You can paste full addresses like https://www.contoso.com/home.html; they’re tidied up when you save.

Small images

Otherwise, keep images visible when narrower or shorter than px

Privacy

This extension has no network access, no analytics and no remote code. Settings are stored only in this browser.
