BSD Image Hider – How to use

Images on websites are replaced by a grey striped box. The page layout stays the same, so websites keep working. You decide, site by site and page by page, what gets hidden.

Tip: pin the extension so its button is always visible: click the puzzle-piece icon in the toolbar, then the pin next to BSD Image Hider.

1. The three modes

ModeWhat it does
Show imagesNothing is hidden.
Hide imagesPictures are hidden. Small icons, buttons and logos stay visible, so sites stay easy to use.
Hide everythingPictures and small icons, logos and SVG icons are all hidden.

Every site uses the default (Hide images, unless you change it in Settings). You can give any site, page or section its own mode.

2. Show a single image

Move the mouse over a hidden image. A small 👁 appears in its corner: click it to show that image, and click ↺ to hide it again.

Keyboard: hover the image and press Alt+A to show it, Alt+Z to hide it.

3. The toolbar button

Click the extension’s button. The box at the top tells you what’s happening on this page and which rule decided it.

ControlWhat it does
This site: Show · Hide · Hide all · DefaultSets the mode for every page of this website. Default removes the site rule.
This page only: Show · Hide · Hide all · As siteSets the mode for just this page. As site removes the page rule, so the page follows the site again.
Pause this tabShows all images in this tab until you unpause it or close the tab.
Show all images on this page onceShows everything until you reload or leave the page.
Pause everywhereTurns hiding off in every tab until you unpause.

4. Settings: managing many sites and pages

Open it from the popup (Settings & rules). There you can:

  • Choose the default for all other sites: Hide images or Hide everything.
  • Change the size below which images count as small icons (48 pixels unless you change it).
  • See all your rules in one list, change a rule’s mode, delete it, or add a new one.

How to write a rule

You typeIt covers
contoso.comThe whole site, including subdomains like shop.contoso.com
contoso.com/home.htmlExactly that one page. Endings like ?ref=email or #contact are ignored.
contoso.com/Only the site’s front page
contoso.com/blog/*Every page whose address starts with contoso.com/blog/
recipesAny address containing the word “recipes”

Which rule wins?

The most specific one: a page rule beats a section rule, a section rule beats a site rule, and a site rule beats the default.

You wantRules
Hide everything on a site, but show images on a few pagescontoso.com → Hide everything
contoso.com/home.html → Show images
Show images on a site, but hide them in one sectioncontoso.com → Show images
contoso.com/news/* → Hide images
Show images on just a few pages of a sitecontoso.com/about.html → Show images
contoso.com/team.html → Show images

Good to know

  • Images still download in the background; they’re just not shown. This doesn’t save data.
  • On some pages an image may flash for a split second while the page loads.
  • Not covered: icons drawn with special fonts (they’re text, not images) and the little site icon on the browser tab.
  • Extensions can’t run on the browser’s own pages (settings, the extension store, the new tab page).
  • If a page looks wrong, use Pause this tab or Show all images on this page once.

Privacy

This extension has no network access, no analytics and no remote code. Your settings and rules are stored only in this browser and never leave it.
